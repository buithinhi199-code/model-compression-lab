# 2. 当前模型状态

当前模型：

    Qwen3-VL-4B-SFT-LoRA

当前看到的目录包括：

-   qwen3vl-4b-sft-lora-r32-b32-0203
-   merged

其中：

    adapter_model.safetensors
    adapter_config.json

属于 LoRA adapter。

而：

    merged/

表示 LoRA 已经合并后的完整模型。

LoRA 合并公式：

\[ W\_{merged}=W\_{base}+`\Delta `{=tex}W \]

部署阶段优先使用 merged 模型，不需要单独加载 LoRA。

# 3. HuggingFace模型文件结构解析

## 3.1 model.safetensors

作用：

保存模型全部权重。

包括：

### Vision Encoder

作用：

图片/视频 → 视觉特征。

流程：

    Image / Video
    ↓
    Patch Embedding
    ↓
    Vision Transformer
    ↓
    Visual Tokens

------------------------------------------------------------------------

### Projector

作用：

连接视觉模块和语言模型。

例如：

Vision Encoder输出：

    1024维

LLM输入：

    2048维

通过线性映射：

    Visual Feature
    ↓
    Projector
    ↓
    LLM Token

------------------------------------------------------------------------

### LLM Decoder

负责文本生成。

结构：

    Embedding

    ↓

    28层 Transformer

    ↓

    LM Head

    ↓

    Next Token

------------------------------------------------------------------------

# 4. config.json结构解析

## 模型类型

    model_type: qwen3_vl

表示：

Qwen3-VL多模态模型。

------------------------------------------------------------------------

## Language Model参数

### hidden_size

    2048

表示每个token的隐藏维度。

------------------------------------------------------------------------

### num_hidden_layers

    28

表示Transformer层数。

------------------------------------------------------------------------

### num_attention_heads

    16

表示Attention头数量。

------------------------------------------------------------------------

### num_key_value_heads

    8

表示使用GQA结构。

16个Query heads共享8组KV heads。

优势：

降低KV Cache占用。

------------------------------------------------------------------------

# 5. Vision Config解析

主要参数：

    depth:24

表示视觉Transformer有24层。

    patch_size:16

表示图片按照16×16区域切分patch。

    hidden_size:1024

表示视觉token维度。

------------------------------------------------------------------------

# 6. processor配置解析

## processor_config.json

负责图片输入处理。

例如：

    do_resize=true
    do_normalize=true

表示：

输入图片需要resize和归一化。

归一化：

\[ x'=`\frac{x-\mu}{\sigma}`{=tex} \]

------------------------------------------------------------------------

## video_preprocessor_config.json

负责视频输入。

例如：

    fps:2
    max_frames:8

表示：

视频采样2帧/s，最多输入8帧。

------------------------------------------------------------------------

# 7. tokenizer文件解析

## tokenizer.json

负责：

文本 ↔ token id转换。

## vocab.json

保存：

token到id映射。

## merges.txt

保存BPE合并规则。
